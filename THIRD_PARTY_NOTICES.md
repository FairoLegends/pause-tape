`three.module.min.js` has one change from the published build: its import path points to `three.core.min.js` instead of `three.core.js`, so the minified files load each other. The files in `assets/vendor/addons/` are copied unchanged except that `from 'three'` became a relative path to `three.module.min.js`, because the page has no import map.

The `.webp` files in `assets/room/` are resized, re-encoded copies of the `.jpg` files beside them (made with Pillow), so the page loads about 0.3 MB instead of 2 MB. The `.jpg` originals keep the C2PA content credentials; the copies don't carry them. Every sound in the app is generated in code with the Web Audio API (`js/sound.js`): there are no audio files.
